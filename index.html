Варианты дизайна

Три концептуальных направления для презентации заказчику. Каждое — полностью рабочий интерфейс с demo-данными, фильтрами, лайтбоксом и переключением темы.

Направление А

Архивная мастерская

Тёплая палитра (Aged Ebony), Source Serif 4, хронологический корешёк слева. Уютная библиотека исследователя.

 Направление Б

Институциональное досье

Светлая тема (Linen), PT Serif, метафора картотеки. Официальный документ с цветными табами.

 Направление В

Хроника эпох

Цветокод эпох (gold/red/blue), Cormorant Garamond, timeline-навигация. Каждая эпоха — свой визуальный мир.

 Текущий

Текущий demo

Базовый вариант (dark + gold, Playfair Display). Для сравнения с новыми направлениями.

Документация

Требования

  • GAP-анализ — что нужно vs что есть (~70% gap)
  • Техническое задание — модель данных, UI, API, деплой
  • Спецификация — полная ТЗ (v3.0, разделы 17-18)

Дизайн

  • Консультация по дизайну — аудит текущего UI, 3 направления, сценарии использования, стратегия роста
  • Дизайн-система — токены, типографика, компоненты, motion

О проекте

Исторический архив СПбГТИ — каталог фото, видео и документов института с 1828 года. В 2028 году институту исполняется 200 лет.

Стек: Directus 10.12.0 + PostgreSQL 16 + nginx + FFmpeg

Деплой: Docker на сервере 85.143.101.97 (прод) / Docker Compose (локально)

Статус: v1.0.0, работает. 1000–10000 файлов, множество сотрудников и выпускников как загрузчики.
