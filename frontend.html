Управление справочниками, статистика, публикация записей.

Текущее состояние

  • Vanilla HTML/CSS/JS, zero dependencies
  • 4 фильтра: категория, десятилетие, поиск, год
  • Шрифты: Playfair Display (заголовки) + Inter (текст)
  • Тёмная тема с gold акцентами (#c9a96e)
  • Masonry-сетка: 4→3→2→1 колонки (адаптив)
  • Лайтбокс с метаданными (дата, категория, описание)
  • Видео: кастомный плеер + FFmpeg миниатюры
  • Авторизация через JWT (только загрузка)
  • Статический токен для чтения галереи
  • Слайд-шоу (5 сек, фото только)
  • Ленивая загрузка изображений

Целевой интерфейс

  • Кастомный UI (не стандартная админка Directus)
  • 6 фильтров: год, факультет, тип, персона, событие, теги
  • Timeline-навигация по десятилетиям
  • Персональный поиск (найти себя по ФИО)
  • Цветовая кодировка эпох (до 1917 / 1917–1991 / после 1991)
  • Адаптивный дизайн (mobile-first)
  • Доступность WCAG 2.2 AA
  • Переключатель темы (light/dark)
  • Связанные записи (люди на фото → все фото с этим человеком)
