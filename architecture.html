Режимы эксплуатации

🔒 Внутренний архив

Текущий режим. Доступ через VPN или локальную сеть. 5–10 сотрудников. Базовая авторизация.

🌐 Публичный архив

Целевой режим. Доступ из интернета. 50–200 пользователей (выпускники, студенты). JWT, rate limiting, CDN.

Навигация по слоям

  • Клиентская часть → — UI, поиск, фильтры, галерея
  • API слой → — эндпоинты, авторизация, фильтрация
  • Хранилище и базы данных → — модель данных, PostgreSQL, файлы
  • Инфраструктура → — Docker, nginx, SSL, деплой
