1. Введение

1.1. Контекст

Фонд «Технологическому институту — 200 лет» эксплуатирует систему электронного архива исторических материалов СПбГТИ по адресу `archive.ti200.ru`. Текущая версия (v1.0.0) обеспечивает базовый функционал: загрузку файлов, публичную галерею, минимум фильтров.

1.2. Проблема

Текущий архив работает как хранилище (загрузил → посмотрел), но не как сервис для поиска и навигации. Основные проблемы:

  • Нет структурированных метаданных (факультеты, персоны, события)
  • Нет связей между записями (одно фото не привязано к людям/событиям)
  • Фильтры ограничены (только категория и десятилетие)
  • Интерфейс не adapté для не-технических пользователей (выпускники, сотрудники)

1.3. Ожидаемый результат

Архив должен стать живым мемориальным порталом, где:

  • Выпускник находит «свой» выпуск и видит всех однокурсников
  • Сотрудник быстро находит все материалы по факультету за определённый год
  • Каждая запись связана с людьми, событиями и темами
  • Навигация возможна по 5 осям: хронология, структура, персоны, события, темы

4. Функциональные требования

4.1. Управление справочниками

4.1.1. Справочник персон

Назначение: Хранение информации о людях, связанных с институтом.

Операции:

  • Создание / Редактирование / Удаление карточки
  • Поиск по имени (частичное совпадение)
  • Фильтр по роли, факультету, году выпуска
  • Просмотр всех связанных записей архива

4.1.2. Справочник факультетов

Назначение: Отражение исторической структуры института.

Начальные данные: Исторические факультеты СПбГТИ (9 шт.)

4.1.3. Справочник событий

Назначение: Фиксация значимых событий и мероприятий.

4.1.4. Справочник тегов

Назначение: Тематическая классификация записей.

Начальные данные: Базовые тематические теги (8 шт.)

---

4.2. Связи между записями

4.2.1. Запись ↔ Персоны

Тип: Many-to-many

Назначение: Позволяет привязать одну запись к нескольким людям (и наоборот).

Примеры использования:

  • Фото выпускного 1985 года связано с 20 выпускниками (тип: «На фото»)
  • Фотография Иванова И.И. связана с 50 записями (тип: «Автор»)

4.2.2. Запись ↔ События

Тип: Many-to-many

Назначение: Привязка записей к событиям (мероприятиям, выпускным, конференциям).

Пример: Все фото с Дня открытых дверей 2023 года связаны с событием «День открытых дверей 2023».

4.2.3. Запись ↔ Теги

Тип: Many-to-many

Назначение: Тематическая классификация.

Пример: Запись имеет теги «Научные лаборатории», «1980-е», «Физический факультет».

4.3. Интерфейс загрузки

URL: `/upload`

Для кого: Редакторы

Требования:

  • Drag & drop загрузка (множественная)
  • Автоматическое определение типа файла (фото/видео/документ)
  • Обязательные поля: Название, Файл
  • Рекомендуемые поля: Год, Факультет
  • Дополнительные поля: Персоны, Событие, Теги
  • Прогресс загрузки
  • Предпросмотр перед загрузкой
  • Статус новой записи: `draft`

---

4.4. Интерфейс просмотра

URL: `/browse`

Для кого: Все пользователи (Наблюдатели, Редакторы, Администраторы)

Фильтры:

Отображение:

  • Masonry-сетка (как текущая галерея)
  • Лайтбокс для просмотра
  • Информация о записи: название, дата, факультет, персоны, событие
  • Навигация между записями

---

4.5. Админ-панель

URL: `/admin`

Для кого: Администраторы

Функции:

  • Управление справочниками (персоны, факультеты, события, теги)
  • Просмотр статистики (всего записей, по факультетам, по персонам)
  • Публикация записей (draft → published)
  • Массовые операции (добавление тегов, привязка к событиям)
  • Экспорт данных (CSV, JSON)
