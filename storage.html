Хранилище и базы данных

Где лежат данные: записи, справочники, файлы

Два типа хранилища

💾 База данных (PostgreSQL)

Хранит записи, справочники, связи, пользователей. Это «мозг» системы: кто загрузил, когда, куда привязано.

📁 Файловое хранилище

Хранит сами файлы (фото, видео, документы). Это «тело»: JPEG, MP4, PDF на диске сервера.

Текущее состояние

  • 1 таблица: Archive (id, title, file, category, date_taken, decade, location, people, status)
  • Файлы: /var/lib/directus/uploads (управляется Directus)
  • Нет справочников: факультеты, персоны, события — только текстовые поля
  • Нет связей: между записями
  • people: текстовое поле (не структурированное)

Файлы

  • Текущее: файлы в /var/lib/directus/uploads, управляются Directus
  • Целевое: то же хранилище + миниатюры (FFmpeg) + CDN для публичного доступа
  • Лимит: 128MB на файл
  • Типы: фото (JPEG, PNG, TIFF), видео (MP4, WebM), документы (PDF)
