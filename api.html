Как интерфейс «говорит» с базой данных

Что такое API

API — это «язык» между интерфейсом и базой данных. Когда вы ищете фото по факультету, интерфейс отправляет запрос через API, а API возвращает подходящие записи.

Представьте: вы звоните в справочное бюро и говорите «Покажите мне все фото ФЭТ за 1985 год». API — это оператор, который принимает ваш запрос и возвращает результат.

Целевой API

Расширенный API с группировкой по назначению:

ГруппаЭндпоинтыОписание
Записи/items/ArchiveCRUD + фильтры (год, факультет, тип, персона, событие, теги)
Персоны/items/personsСправочник людей (студенты, преподаватели, выпускники)
Факультеты/items/facultiesСправочник факультетов (9 шт.)
События/items/eventsСправочник событий (выпускные, конференции)
Теги/items/tagsТематические метки (8 шт.)
Связи/items/archive_persons, archive_events, archive_tagsMany-to-many связи

Фильтрация

API поддерживает комбинированные запросы:

Поиск по году:
GET /items/Archive?filter[date_taken][_gte]=1980&filter[date_taken][_lte]=1989
Поиск по факультету:
GET /items/Archive?filter[faculty_id][_eq]=<uuid>
Комбинированный поиск:
GET /items/Archive?filter[faculty_id][_eq]=<uuid>&filter[tags][_in]=<tag_uuid>
