Пользователь нажимает «Найти» → сервер ищет → возвращает результат

1

Запрос

↓
2

↓
3

Поиск в базе

Ищет записи, которые совпадают со всеми условиями

↓
4

Результат

Возвращает список: превью, название, год, ссылки
