Текущее состояние

  • Сервер: Ubuntu 24.04 LTS на 85.143.101.97
  • Docker Compose: 3 сервиса (nginx, directus, directus-db) + 1 внутренний (thumbnails)
  • SSL: Let's Encrypt (до сентября 2026)
  • Домен: archive.ti200.ru
  • Образы: Directus 10.12.0, PostgreSQL 16-alpine, nginx:alpine, FFmpeg (alpine)
  • Объёмы: 3 Docker volume (db-data, uploads, database)
  • Нет health-checks
  • Нет автоматических бэкапов
  • Нет мониторинга

Целевая инфраструктура

  • Docker Compose с health-checks для всех сервисов
  • Автоматические бэкапы: PostgreSQL (pg_dump) + uploads (rsync) — ежедневно
  • SSL: автоматическое обновление (certbot)
  • Мониторинг: uptime + disk space + Docker stats
  • Rate limiting на nginx (100 req/min для API)
  • CORS: настроен для archive.ti200.ru
  • Кэширование: статика (1 год), API (no-cache)

Два режима

🔒 Внутренний архив

Текущий режим

  • Доступ: VPN / локальная сеть
  • Пользователи: 5–10 сотрудников
  • Авторизация: статический токен
  • SSL: не обязателен
  • Бэкап: ручной
  • Мониторинг: нет

🌐 Публичный архив

Целевой режим

  • Доступ: интернет (archive.ti200.ru)
  • Пользователи: 50–200
  • Авторизация: JWT + роли
  • SSL: обязателен (Let's Encrypt)
  • Бэкап: ежедневный автоматический
  • Мониторинг: uptime, disk, Docker
  • Rate limiting: 100 req/min
