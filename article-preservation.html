Долгосрочное хранение: как сохранить архив на 200 лет

Цифровая деградация, форматы, резервное копирование и стратегия, которая переживёт поколения

1. Цифровая деградация: файлы не вечны

Мы привыкли думать, что «цифровое = вечное». Это неправда. Цифровые данные умирают быстрее бумажных:

  • Физическая деградация: HDD — 3-5 лет, SSD — 5-10 лет, оптические диски — 5-20 лет
  • Обновление форматов: JPEG может не читаться через 50 лет. Flash-анимации уже не читаются
  • Устаревание софта: Directus может исчезнуть через 10 лет. Файлы станут недоступны
  • Ошибка хранения: одно повреждённое место на диске = потеря данных

Факт: Library of Congress оценивает, что средний срок жизни цифрового формата — 15-20 лет. После этого нужна миграция. Для 200-летнего архива это значит минимум 10 миграций.

Но есть хорошая новость: с правильной стратегией цифровые данные можно хранить бесконечно. Секрет — в трёх принципах: правильные форматы, резервные копии, регулярная миграция.

2. Форматы для долгосрочного хранения

Не все форматы равны. Вот рекомендации по типам данных:

Тип Master-формат Публичный формат Почему именно эти
Фото TIFF (без сжатия) JPEG / WebP TIFF — открытый стандарт, не зависит от софта. JPEG — универсален
Видео FFV1 / MKV H.264 / MP4 FFV1 — lossless, открытый. H.264 — воспроизводится везде
Документы PDF/A PDF PDF/A — архивный стандарт, не зависит от шрифтов/софта
Текст Plain text (UTF-8) HTML Plain text читается всегда и везде
Метаданные XML (Dublin Core) JSON XML — стандарт, парсится любым языком

Принцип: Всегда хранить два экземпляра: master (максимальное качество) и рабочий (оптимизированный для просмотра). Master-файл трогать нельзя. Рабочий — можно конвертировать.

3. Стратегия 3-2-1

Это «золотой стандарт» резервного копирования, который используют архивы всего мира:

3 копии данных

Оригинал + две резервные копии. Если одна пропадёт — две других спасают.

2 разных типа носителя

Диск + облако. Или диск + лента. Если один тип носителя выйдет из употребления — второй продолжит работать.

1 копия offsite

Вне основного здания. Пожар, затопление, кража — offsite-копия остаётся.

Расписание бэкапов

Тип Частота Хранение Цель
Ежедневный Каждую ночь 7 дней Откат за последний день
Еженедельный Каждое воскресенье 4 недели Откат за последнюю неделю
Ежемесячный 1 числа 12 месяцев Откат за месяц
Ежегодный 31 декабря Бессрочно Архивная копия года

4. Миграция форматов

Каждые 5-7 лет нужно проверять: все ли форматы ещё читаются?

Год 0 — Запуск

Все файлы в актуальных форматах: TIFF, PDF/A, MKV. Система работает.

Год 5 — Первая проверка

Проверяем читаемость всех форматов. Конвертируем устаревшие. Обновляем софт.

Год 10 — Миграция

Если формат устарел — конвертируем master-копии. Публичные форматы обновляем автоматически.

Год 20 — Капитальная миграция

Возможно, меняется вся система хранения. Экспорт в открытые форматы. Переезд на новую платформу.

Год 50+ — Поколенческая миграция

Технологии могут измениться кардинально. Принцип: данные в открытых форматах можно перенести на любую новую систему.

5. Инфраструктура хранения

Текущий стек СПбГТИ

  • PostgreSQL 16: хранит метаданные (справочники, связи, описания)
  • Directus 10.12.0: API + админка + интерфейс
  • Docker: контейнеризация (легко перенести на другой сервер)
  • nginx: раздача статики, SSL, проксирование
  • Диск сервера: хранение файлов (фото, видео)

Что нужно добавить

Компонент Зачем Стоимость
Автоматический pg_dump Бэкап базы данных раз в сутки 0 руб (cron job)
rsync → offsite Копирование файлов на второй сервер ~2000 руб/мес (аренда VPS)
Облачный бэкап 3-я копия в облаке (S3/MinIO) ~1000 руб/мес
Checksums Проверка целостности файлов 0 руб (встроенные инструменты)
Мониторинг Уведомления о проблемах 0 руб (Uptime Kuma)

Итого: ~3000 руб/мес (~36 000 руб/год) для полноценной стратегии 3-2-1. Это инвестиция в сохранность 200-летнего наследия.

6. Как это делают в мире

LOCKSS (Lots of Copies Keep Stuff Safe)

Программа Стэнфорда. Принцип: чем больше копий, тем безопаснее. Участвуют 500+ библиотек мира. Каждая хранит свою копию + копии соседей.

CLOCKSS (Controlled LOCKSS)

«Тёмный архив». Срабатывает только если оригиналы уничтожены. Хранит копии всех научных журналов. Страховка для цивилизации.

Portico

Архив научных публикаций. Хранит миллионы статей. Используется, когда журнал прекращает выходить или сайт падает.

National Digital Preservation (NDPP)

Программы национального уровня: Library of Congress (США), National Archives (UK), Национальная библиотека (Россия). Государственное финансирование долгосрочного хранения.

7. План для СПбГТИ

Немедленно (неделя 1)

Настроить ежедневный pg_dump + rsync файлов. Это базовая защита от потери данных. Стоимость: 0 руб.

Краткосрочно (месяц 1-3)

Подключить облачный бэкап (Яндекс.Облако / Selectel). Настроить checksums. Внедрить мониторинг. Стоимость: ~3000 руб/мес.

Среднесрочно (год 1)

Установить стандарты форматов: TIFF для фото, PDF/A для документов. При загрузке — автоматическая конвертация master-копии. Проверить все существующие файлы.

Долгосрочно (год 3-5)

Первая проверка читаемости форматов. Обновление master-копий при необходимости. План миграции на следующие 5 лет.

Принцип: Архив, который невозможно найти — не существует. Архив, который невозможно прочитать — мёртв. Архив, который невозможно скопировать — хрупок. СПбГТИ должен строить архив, который найти, прочитать и скопировать можно всегда.
