Аудит и рекомендации

Дата: 04.09.2026

Объект: archive.ti200.ru — цифровой архив Санкт-Петербургского государственного технологического института (1828–2028)

---

1. Аудит текущего дизайна

1.1. Что работает хорошо

Палитра целостна. Тёмный фон `#0a0a0f` с золотым акцентом `#c9a96e` — правильный выбор для исторического архива. Золото ассоциируется с архивной ценностью, тёмный фон создаёт контраст для фотографий. Отношение контрастности текста `#e8e6e3` на `#0a0a0f` — 15.2:1 (превышает WCAG AAA).

Типографика разумна. Playfair Display для заголовков — классический выбор для «премиальных» проектов, Inter для тела — хорошая читаемость. Google Fonts подключены, зависимостей нет.

Фильтры интуитивны. Pill-кнопки с активным состоянием (золотой фон + чёрный текст) — стандартный паттерн, пользователь сразу понимает механику.

Masonry-сетка функциональна. Адаптивная (4→3→2→1 колонки), lazy loading, скелетоны при загрузке — технически грамотная реализация.

Слайд-шоу с прогресс-баром. Золотая полоса внизу — элегантная деталь, создаёт ощущение «кинематографичности».

1.2. Что чувствуется как шаблон / dated

Playfair + Inter + тёмная тема + золото — это LOOK #1 из AI-шаблонов. Комбинация «trending» с 2022 года. Подходит для luxury/restaurant, но не для научного архива. Ассоциация: «ещё один премиальный сайт на фрилансе», а не «/iforial института с 200-летней историей».

Золотой `#c9a96e` слишком «ювелирный». Это цвет украшений, а не документов. Для архива лучше было бы cooler gold (ближе к antique brass / parchment) или вовсе другой акцент —.sepia, aged paper, institutional blue.

Нет визуальной иерархии эпох. Фильтр «1930-е, 1940-е...» — функциональный, но визуально плоский. Все десятилетия выглядят одинаково. Нет ощущения хронологии, нет «временного слоя».

Header статичен и пустоват. Заголовок «Исторический архив» + подпись «Фотохроника института» + кнопка «Слайд-шоу». Нет визуального якоря: ни года основания, ни эмблемы, ни статистики, ни атмосферного изображения.

Карточки в галерее — стандартный Masonry pattern. Hover-эффект (scale + translateY + box-shadow) — тривиальный. Overlay снизу —预测able. Ничего, что бы говорило «это архив СПбГТИ», а не «это галерея с Unsplash».

Кнопка «Слайд-шоу» — единственный call-to-action. Нет secondory action: «Посмотреть по эпохам», «Найти человека», «О проекте».

Upload.html — чисто функциональный. Нет атмосферы, нет контекста. Страница загрузки выглядит как техническая форма, а не как «вклад в историю института».

Нет light/dark theme toggle (описан в SPEC, но не в текущем коде). Для внутреннего инструмента это может быть важно: сотрудники работают днём, им нужна светлая тема.

1.3. Пропущенные возможности

  • Нет timeline-навигации. 200 лет истории — это идеальный кейс для хронологической шкалы.
  • Нет персональной оси. Поле `people` — текстовое. Нет карточек персон.
  • Нет factural texture. Архивные интерфейсы часто используют текстуры бумаги, крафта, патины — создаёт ощущение «физического» архива.
  • Нет typographic character. Inter — нейтральный sans-serif. Для архива можно было бы использовать что-то с更大的 character: Source Serif, Lora, Merriweather.
  • Footer примитивен. «Архив СПбГТИ · v1.0.0» — техническая строка. Здесь место для навигации, контактов, информации о проекте.

2. Направления дизайна

Направление А: «Архивная мастерская» (Archival Atelier)

Настроение: Уютная библиотека / исследовательская комната. Тёплый свет, дерево, бумага. Не музейный пафос, а рабочее пространство исследователя.

Палитра:

Типографика:

  • Заголовки: Source Serif 4 (Google Fonts) — научный serif с характером, не «премиальный» Playfair
  • Тело: IBM Plex Sans — технический, чистый, институциональный
  • Моно/данные: IBM Plex Mono — для дат, инвентарных номеров, метаданных

Сигнатура: Вертикальная хронологическая полоса слева — «книжный корешёк» с отметками эпох. При скролле подсвечивается текущее десятилетие.

Компоненты:

  • Карточки: мягкий border `1px solid var(--shell)`, без box-shadow. При hover — subtle glow warmth (`box-shadow: 0 0 20px rgba(184,148,90,0.08)`)
  • Фильтры: pill-кнопки с border (текущий паттерн), но активное состояние — border gold + текст gold (без заливки)
  • Lightbox: фон `rgba(26,22,18,0.96)`, overlay-info слева (side panel), а не снизу
  • Header: hero-секция с large year counter «1828 — 2028» + «200 лет» + miniature archival pattern

Чем отличается от шаблона: Тёплая вместо холодной палитры. Source Serif вместо Playfair. Акрхивная зелёная лампа как вторичный акцент. Хронологическая навигация как структурный элемент.

---

Направление Б: «Институциональный досье» (Institutional Dossier)

Настроение: Официальный документ / досье / форма. Строгий, чистый, с акцентом на структуру данных. Как найти что-то в картотеке, но digital.

Палитра:

Типографка:

  • Заголовки: PT Serif (от Параболы, русифицированный) — академический, «документальный»
  • Тело: PT Sans — комплементарный, чистый
  • Данные: PT Mono — для дат, номеров, инвентарных

Сигнатура: «Карточка дела» — каждый элемент галереи отображается как карточка с верхним табом (как в ящике картотеки). Верхний таб = десятилетие / категория.

Компоненты:

  • Карточки: белый фон, чёткий border `1px solid #d4cfc7`, верхний таб-элемент с цветом категории
  • Фильтры: горизонтальная «полка» с ярлыками (как в картотеке)
  • Lightbox: белый фон, metadata panel справа (как карточка дела),较大的 type size для читаемости
  • Header: гриф «Дело №...» + «Исторический архив СПбГТИ» + дата открытия/закрытия (1828–2028)

Чем отличается от шаблона: Светлая тема по умолчанию (институциональная). PT Serif от Параболы — культурно релевантный. Метафора картотеки/дела. Не «премиальный dark UI», а «рабочий архивный интерфейс».

---

Направление В: «Хроника эпох» (Chronicle)

Настроение: Временная лента / хроника / летопись. Каждая эпоха — отдельный визуальный мир. Навигация по времени — основной interaction pattern.

Палитра:

Типографика:

  • Заголовки: Cormorant Garamond — элегантный, «исторический», с характером
  • Тело: Inter — оставляем (хорошо работает)
  • Данные: JetBrains Mono — для дат, таймкодов видео

Сигнатура: Timeline как основной навигационный элемент. Вертикальная лента слева с «узлами»-десятилетиями. Каждое десятилетие — свой цвет-акцент. При наведении на узел — предпросмотр контента эпохи.

Компоненты:

  • Карточки: border-radius 4px (menьше текущего 16px), subtle border, при hover — левая border-line цвета эпохи
  • Фильтры: горизонтальная timeline-шкала (скроллируемая), с подписями десятилетий
  • Lightbox: фон rgba(15,15,18,0.98), large image + side metadata panel + related items carousel внизу
  • Header: large timeline visualization — «1828 ──────── 1928 ──────── 2028» с промежуточными узлами

Чем отличается от шаблона: Цветовая кодировка эпох (не монотонная палитра). Timeline как primary navigation. Cormorant Garamond вместо Playfair — другой character. Цвет-кодирование = мгновенная ориентация в пространстве времени.

3. Сценарии использования

3.1. Персона: Виктория, выпускница 1987 года

Роль: Преподаватель в другом вузе, готовит доклад к юбилею кафедры

Задача: Найти фото своего выпуска и преподавателей

Путь:

1. Заходит на archive.ti200.ru (ей дал ссылку одногруппник)

2. Видит timeline, сразу находит «1980-е»

3. Фильтрует по факультету «ФРТК» и категории «Студенты»

4. Находит 12 фото своего выпуска

5. Нажимает на фото — в лайтбоксе видит имена людей (если заполнены)

6. Скачивает 3 фото для доклада

Боль: Сейчас нет фильтра по факультету. Нет имён на фото. Приходится листать все 1980-е.

Радость: Если бы была персональная ось — нашла бы себя по фамилии и сразу все фото с её участием.

3.2. Персона: Алексей, архивист института (70 лет)

Роль: Работник библиотеки, сканирует старые фото

Задача: Загрузить 50 фото из коробки с негативами 1960-х

Путь:

1. Заходит через upload.html

2. Авторизуется (уже знает пароль)

3. Перетаскивает 50 файлов

4. Заполняет категорию, дату, место

5. Жмёт «Загрузить»

6. Видит прогресс-бар

Боль: Сейчас нет возможности указать «описание» при загрузке. Нет превью перед загрузкой. Нет автозаполнения десятилетия по дате.

Радость: Если бы при вводе даты автоматически заполнялось десятилетие. Если бы можно было добавить описание и теги.

3.3. Персона: Мария, студентка 3 курса

Роль: Участник студенческого научного общества, пишет эссе о традициях института

Задача: Найти фото студенческой жизни разных эпох для сравнения

Путь:

1. Заходит на архив

2. Фильтрует по «Студенты»

3. Листает фото 1950-х, 1970-х, 2000-х

4. Сравнивает визуально

Боль: Нет тематических подборок. Нет описаний к фото. Нет context: «что это за мероприятие?».

Радость: Если бы были тематические коллекции: «Студенческая жизнь», «Научные лаборатории», «Институтские здания».

3.4. Персона: Дмитрий, IT-специалист института

Роль: Отвечает за сервер, помогает с технической настройкой

Задача: Проверить, работает ли архив, посмотреть статистику

Путь:

1. Заходит на archive.ti200.ru

2. Смотрит: сколько материалов, последняя загрузка

3. Проверяет, нет ли ошибок в консоли

Боль: Нет dashboard/статистики. Нет health-check страницы.

Радость: Если бы был простой stats bar: «1,247 материалов · 89 персон · Последнее обновление: 3 дня назад».

3.5. Персона: Анна, сотрудник HR-отдела

Роль: Готовит приветственный пакет для новых сотрудников

Задача: Найти фото зданий института для презентации

Путь:

1. Заходит в архив

2. Фильтрует по «Здания»

3. Скачивает 5-6 фото главного корпуса разных лет

4. Составляет слайд-шоу или коллаж

Боль: Нет возможности создавать «подборки» / «альбомы». Нет bulk-download.

Радость: Если бы можно было собрать подборку и скачать архивом.

3.6. Персона: Профессор Иванов, выпускник 1975 года

Роль: Заведующий кафедрой, хочет «найти себя»

Задача: Узнать, есть ли его фото в архиве

Путь:

1. Заходит в архив

2. Вводит свою фамилию в поиск

3. Видит 3 фото: одно как студента, два как преподавателя

4. Смотрит карточку персоны с биографией

Боль: Сейчас поле `people` — текстовое, без связей. Поиск по фамилии не работает.

Радость: Если бы была «карточка персоны» с агрегацией всех связанных материалов.

3.7. Персона: Сергей (разработчик), администратор

Роль: Тот, кто поддерживает систему

Задача: Добавить нового пользователя, проверить права

Путь:

1. Заходит в Directus admin

2. Создаёт роль «Alumni»

3. Настраивает права

4. Проверяет доступ

Боль: Админка — стандартная Directus, без кастомизации под архив.

Радость: Если бы был кастомный admin dashboard с визуальной статистикой.

5. Сигнатура: Элемент узнаваемости

Проблема

Сейчас архив выглядит как «любой dark UI с gold accent». Ничего не говорит «СПбГТИ» или «200 лет истории».

Решение: «Хронологический корешёк» (Chronological Spine)

Что это: Вертикальная полоса слева от основного контента — «книжный корешёк» с отметками десятилетий. Каждое десятилетие — узел на полосе. Текущее (выбранное) десятилетие подсвечивается.

Как выглядит:

```

│

│ ●─── 1828-е (основание)

│ │

│ ●─── 1850-е

│ │

│ ●─── 1880-е

│ │

│ ●─── 1910-е

│ │

│ ◉═══ 1940-е (война) ← активное десятилетие

│ │

│ ●─── 1960-е

│ │

│ ●─── 1980-е

│ │

│ ●─── 2000-е

│ │

│ ●─── 2020-е

│

```

Почему это работает:

1. Мгновенная ориентация. Пользователь видит, «где» он во времени.

2. Визуальная дифференциация. Каждое десятилетие — отдельный узел, не просто текст в фильтре.

3. Ассоциация с книгой/архивом. Корешёк = книга = знание = архив.

4. Уникальность. Ни один из трёх AI-шаблонов не использует这种element.

5. Масштабируемость. Работает для 10 десятилетий и для 20.

Техническая реализация:

  • CSS: `position: fixed; left: 0; top: 50%; transform: translateY(-50%); height: 60vh;`
  • Узлы: `border-radius: 50%; width: 12px; height: 12px;` с `transition` при hover
  • Линия: `width: 2px; background: var(--surface3);` с `::before` для активного отрезка
  • Mobile: горизонтальная версия внизу экрана (bottom sheet)

Дополнительные «маркеры СПбГТИ»:

  • Год основания «1828» в header (large, faint)
  • Факультеты как «разделители» в timeline (горизонтальные линии)
  • Категории цветом: фото = gold, видео = green, документы = blue

6. Рекомендации по реализации

Приоритет 1 (текущий дизайн)

1. Заменить Playfair Display → Source Serif 4 или Cormorant Garamond

2. Добавить в footer информацию: «200 лет СПбГТИ · 1828–2028»

3. Добавить «About» секцию (миссия архива, как обращаться)

4. Сделать заголовок header более выразительным (год основания, статистика)

Приоритет 2 (структура)

1. Реализовать коллекции: Persons, Events, Faculties, Tags

2. Добавить фильтры: факультет, тип файла, конкретный год

3. Timeline-навигация (хотя бы горизонтальная шкала)

Приоритет 3 (аспект)

1. Chronological Spine (вертикальная полоса слева)

2. Light theme (для сотрудников днём)

3. Curated collections (редакционные подборки)
